# leetcode
A github repo for leetcode coding.


## Quick Start

```bash
git clone https://github.com/R-Sh1ki/leetcode.git
cd leetcode

uv sync
```

Before solving the leetcode problems, you need to config the website login tokens first. We give an example environment config file `.env.example`. You can check your cookies under the debug mode (`F12`) on browser and record your own `LEETCODE_SESSION` and `csrftoken` to the config file. Then you can execute the following command:

```bash
mv .env.example .env
```
